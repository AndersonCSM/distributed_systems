# Projeto 5 - Frontend para Deploy com Containers

Aplicacao frontend usada no fluxo de conteinerizacao com Docker e publicacao em AWS (ECR e ECS).

## Requisitos

- Node.js 18+
- npm

## Executar Localmente

```bash
npm install
npm run dev
```

## Scripts Disponiveis

- npm run dev: inicia ambiente de desenvolvimento
- npm run build: gera build para producao
- npm run preview: publica localmente a build
- npm run lint: executa verificacao de lint
